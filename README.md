# Fazle Rabbi — Academic Research Portfolio

Static GitHub Pages website: https://frabbisw.github.io/

The site is hosted from the repository's `master` branch and the root `index.html`. No build step is required.

## Files

- `index.html`: Main portfolio, including About, Research, Publications, Teaching, Experience, and Teams & Service.
- `assets/style.css`: Responsive styles and theme.
- `assets/main.js`: Navigation, publication search/filter, and theme toggle.
- `assets/fazle-rabbi.jpg`: Profile portrait.
- `assets/og-cover.png`: Social sharing image.
- `assets/favicon.svg`: Site icon.
- `publications.json`: Publication metadata. The rendered publication list is already embedded in `index.html`, so updating the JSON alone will not change the published list.
- `cv/Fazle_Rabbi_Public_CV.pdf`: Public CV, prepared in October 2026.

## Updating

Edit `index.html` and, as needed, the styles, scripts, images, publication metadata, and public CV. Commit the changes to `master` to update the site. Verify that all publication statuses, external links, and CV details are current before publishing.

This version uses research-focused, neutral wording and separates research content from teaching and professional experience.
